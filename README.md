# Таймеры

Страница с несколькими таймерами обратного отсчёта на Next.js.

## Возможности

- Добавление любого количества таймеров: название, время в минутах (кнопки `−` / `+`, ручной ввод, пресеты).
- Пауза и продолжение, `+1 мин`, сброс, удаление.
- Звук по умолчанию (синтезированный сигнал) и загрузка своей мелодии (MP3, WAV, OGG, M4A до 20 МБ).
- Мелодия хранится в IndexedDB, таймеры и настройки — в localStorage.
- Уведомления браузера о завершении (по кнопке-колокольчику).
- Светлая и тёмная тема с запоминанием выбора.
- Таймеры продолжают идти в фоновой вкладке; по завершении звучит сигнал до нажатия «Стоп».

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Если порт 3000 занят: `npm run dev:3100` (http://localhost:3100).

Сборка: `npm run build && npm start`.

## Деплой на GitHub Pages

Статическая версия публикуется автоматически при пуше в `main`:

- сайт: https://maltsevnikita.github.io/timers/
- workflow: `.github/workflows/deploy.yml` (собирает `out/` и деплоит через GitHub Actions);
- для подпапки `/timers` в workflow задаётся `PAGES_BASE_PATH=/timers`, локально сборка идёт без префикса;
- проверить локально как на Pages: `$env:PAGES_BASE_PATH="/timers"; npm run build`, затем отдать `out` по пути `/timers/`.

## Старые браузеры

Для устройств, где не работает современный JS/CSS (например, старый планшет на Android 7), есть облегчённая версия: `/lite/`.

- Чистый ES5, обычный CSS, те же функции: добавление, пауза, `+1 мин`, сброс, звук и своя мелодия.
- Основная страница перенаправляет туда браузеры без поддержки `color-mix()` (проверка в inline-скрипте), то есть старые Chromium/Safari, на которые не рассчитан Next 16 и Tailwind 4.
- Ссылка на лёгкую версию также есть в подвале основной страницы.
